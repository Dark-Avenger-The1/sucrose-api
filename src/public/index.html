How the suggestions are made

  1. Match your reading to a glucose level

    Eight levels run from under 80 to 200+ mg/dL. Each has its own limits for sugar, net carbs and saturated fat per 100 g.

  2. Find what adults like you eat

    ECLAT, a frequent-pattern mining method, finds the foods and pairs most common among 1,885 adults in NHANES 2017–2018, split by age group and gender.

  3. Keep what fits the limits

    Every food group and every item inside it is checked against the level’s limits, so the same group can offer fewer items as the level rises.

Build with the API

Four GET endpoints, JSON responses, no API key. Try a request from the documentation page.
