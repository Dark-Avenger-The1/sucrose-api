API documentation

Turn a blood sugar reading, age and gender into food suggestions.

Overview

The Sucrose API serves the ECLAT model (version 2.1, trained on NHANES 2017–2018) through four read-only GET endpoints. Responses are JSON and there is no API key.

Base URL:

https://sucrose-api.onrender.com/api

/food, /combo and /meal-plan wrap their result in an object with data and disclaimer. /glucose-check returns its object directly.

Example request

curl "https://sucrose-api.onrender.com/api/food?glucose=105&age=30&gender=male"

Try it

This sends a real request to the server below.


                        

                    

                


                

                    
Parameters

                    
All parameters go in the query string.

                    

                        

                            
NameTypeUsed byRules

                            
                                
glucosenumberAll endpointsBlood sugar in mg/dL, from 20 to 600.

                                
agenumberEvery endpoint except /glucose-check18 or older. Age groups are 18–39, 40–59 and 60+.

                                
genderstringEvery endpoint except /glucose-checkmale or female, not case-sensitive.

                            
                        

                    

                


                

                    
Glucose check

                    
GET/api/glucose-check

                    
Classifies a reading and returns the limits for its glucose level. Needs only glucose.

                    
Request
curl "https://sucrose-api.onrender.com/api/glucose-check?glucose=105"

                    
Response
{
  "clinicalBand": "Prediabetes",
  "limits": {
    "sugar": 12,
    "net_carb": 45,
    "sat_fat": 10,
    "carb_penalty": 0.15
  },
  "note": {
    "note": "A fasting glucose of 100 mg/dL or more should be confirmed and discussed with a doctor.",
    "disclaimer": "Educational prototype, not medical advice."
  }
}

                    

                        

                            
FieldMeaning

                            
                                
clinicalBandLow (hypoglycemia), Normal, Prediabetes or Diabetes. See Glucose levels.

                                
limitsMost a food can have per 100 g at this glucose level: sugar, net_carb and sat_fat, in grams. carb_penalty is a training setting that rises with each level; clients can ignore it.

                                
noteGuidance text for the reading, plus the disclaimer.

                            
                        

                    

                


                

                    
Foods

                    
GET/api/food

                    
Food groups that adults of your age and gender at your glucose level commonly eat, each with the specific foods that stay within the level’s limits. Groups are ranked by the model, highest first.

                    
Request
curl "https://sucrose-api.onrender.com/api/food?glucose=105&age=30&gender=male"

                    
Response, trimmed to one group and two items
{
  "data": [
    {
      "food": "Fresh fruit",
      "code": 631,
      "net_carb_100g": 13.4,
      "items": [
        {
          "code": 63107010,
          "name": "Banana, raw",
          "net_carb_100g": 20.2
        },
        {
          "code": 63101000,
          "name": "Apple, raw",
          "net_carb_100g": 11.4
        }
      ]
    }
  ],
  "disclaimer": "Educational prototype, not medical advice."
}

                    

                        

                            
FieldMeaning

                            
                                
data[].foodFood group name.

                                
data[].codeFood group code.

                                
data[].net_carb_100gNet carbs per 100 g for the group, in grams.

                                
data[].itemsSpecific foods in the group allowed at this level, each with code, name and net_carb_100g. Can be empty.

                            
                        

                    

                


                

                    
Combos

                    
GET/api/combo

                    
Pairs of food groups that people at your level often eat together.

                    
Request
curl "https://sucrose-api.onrender.com/api/combo?glucose=105&age=30&gender=male"

                    
Response, trimmed to three pairs
{
  "data": [
    {
      "food": [
        "Milk",
        "Fresh fruit"
      ]
    },
    {
      "food": [
        "Fresh fruit",
        "Salad vegetables"
      ]
    },
    {
      "food": [
        "Fresh fruit",
        "Cooked vegetables"
      ]
    }
  ],
  "disclaimer": "Educational prototype, not medical advice."
}

                    
Each food array holds two group names. They match data[].food from /food.

                


                

                    
Meal plan

                    
GET/api/meal-plan

                    
A day’s plan with up to three food groups per meal. No group repeats within the day. A meal’s combo names a pair eaten together, or is null when no unused pair is left. The plan is shuffled on every request, so calling again returns a new one.

                    
Request
curl "https://sucrose-api.onrender.com/api/meal-plan?glucose=105&age=30&gender=male"

                    
Response, trimmed to breakfast, two groups and one item each
{
  "data": {
    "breakfast": {
      "combo": [
        "Salad vegetables",
        "Raw tomatoes"
      ],
      "foods": [
        {
          "food": "Salad vegetables",
          "code": 751,
          "net_carb_100g": 3.7,
          "items": [
            {
              "code": 75113000,
              "name": "Lettuce, raw",
              "net_carb_100g": 1.7
            }
          ]
        },
        {
          "food": "Raw tomatoes",
          "code": 741,
          "net_carb_100g": 2.7,
          "items": [
            {
              "code": 74101000,
              "name": "Tomatoes, raw",
              "net_carb_100g": 2.7
            }
          ]
        }
      ]
    }
  },
  "disclaimer": "Educational prototype, not medical advice."
}

                    
breakfast, lunch and dinner each hold combo and foods. Entries in foods have the same shape as data[] from /food.

                


                

                    
Glucose levels

                    
A reading maps to one of eight levels. Each level caps sugar, net carbs and saturated fat per 100 g of food. Levels below 100 were mined together, as were levels from 120 up; what changes between them is the limits.

Errors

                    
Errors return a JSON body with a single error message.

                    
{
  "error": "age must be 18 or older"
}

                    

                        

                            
StatusWhen

                            
                                
400A parameter is missing or invalid: glucose is required and must be a number, age is required and must be a number, gender is required, age must be 18 or older, gender must be one of: male, female, or glucose must be between 20 and 600 mg/dL.

                                
404The route does not exist, or no recommendation was found for the input.

                                
500Unexpected server error: Internal server error.

                            
                        

                    

                    
Educational prototype, not medical advice. Food responses carry this text in disclaimer; show it wherever you present the results.
